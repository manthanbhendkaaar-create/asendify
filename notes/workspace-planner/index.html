Questions

How should I organise a Notion-style workspace?

Keep a small number of top-level pages, put anything you track (tasks, clients, content, meetings) in a database rather than loose pages, and give each database two or three views for the ways you look at it, such as a board by status and a calendar by date. A Home page with linked views of what matters today ties it together.

Should I use one database or many?

One database per kind of thing: tasks, projects, clients, content and so on. Link them with relations (a task belongs to a project, a project to a client) instead of copying the same information into several places.

What views should each database have?

Use a board for anything that moves through stages, a calendar for anything with a date, a timeline for projects with start and end dates, a gallery for visual items like content or books, and a table or list for quick editing and searching.

Does Asendify Notes have templates for this?

Yes. Asendify Notes has 10 built-in templates: second brain, task board, simple CRM, content calendar, meeting notes, goals (OKRs), habit tracker, journal, reading list and team wiki. The planner tells you which ones match your answers.

Can my team edit the workspace together?

Not in Asendify Notes: each account has one owner, and others can only read, through read-only public links or up to 50 free view-only guests. If your team needs to edit together, the layout from this planner still works in any Notion-style tool that supports shared editing.

Can I import the suggested layout?

You can download it as a Markdown outline and as CSV files with the suggested properties as column headings. Asendify Notes imports Markdown files as pages and CSV files as databases; you then add the views.
