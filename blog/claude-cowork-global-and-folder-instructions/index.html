How do you give Claude Cowork standing instructions with global and folder instructions?

By Manthan Bhendkar · 6 min read · Published 20 November 2026 · Last updated 20 November 2026

Disclosure: Asendify publishes this page and makes some of the options mentioned here; ours are named as ours. Every option is described from its own official page, and prices and features can change, so check before you buy.

Claude Cowork has two places for standing instructions. Global instructions, set in Settings > Cowork, apply to every task you run. Folder or project instructions apply only to tasks inside that folder or project, so they hold context such as your role, file locations and output format. Put rules that never change in global instructions and anything that keeps evolving in a file in the folder.

Key takeaways

  • Global instructions: Settings > Cowork, then Edit next to Global Instructions. They apply to every conversation, whichever project you are in.
  • Project instructions: open the project and use its instructions box; they carry into every task started there.
  • Anthropic's help centre says Claude can update folder instructions during a session; the instructions you type in the project panel do not change on their own.
  • Memory (cloud sessions only) is separate: it learns as you go, while instructions are rules you write and control.
  • Anthropic suggests checking what Claude has taken in by asking "tell me what you know about how I work here".

The three layers of context

Anthropic's help article Get started with Claude Cowork describes global instructions as applying to all sessions, set in Settings > Cowork, and folder instructions as project-specific context for a selected local folder, which Claude can update during a session. Projects themselves group tasks into workspaces with their own files, instructions and memory.

Global instructions: what to put there

Anthropic's onboarding tutorial, Set up Cowork to work the way you do, gives the path: Settings > Cowork, click Edit next to Global Instructions, type and save. Its examples are "save drafts as .docx" and "ask before deleting anything".

Good global instructions are short, stable and about how you want Claude to behave everywhere:

  • Language and spelling ("Use UK English").
  • What to check before acting ("Confirm before sending any email").
  • File habits ("Never overwrite an existing file; save a new version").
  • Tone for anything external ("Plain, polite, no exclamation marks").

Project instructions: what to put there

The same tutorial says project instructions carry into every task started inside the project, and Claude reads them alongside the files in the folder. It suggests including:

  • Your role and function ("I run customer support for a 3-person online shop").
  • Default output format (a spreadsheet, a one-page memo).
  • Where things live across tools ("Orders are in the Google Sheet called Orders 2026; refunds are tagged in Gmail").
  • Judgement calls you want handled the same way each time ("Refunds over £100 need my approval").

For anything that keeps changing, it recommends a file in the folder instead, with an example prompt: "Add what we covered to my notes file."

How this relates to memory

Instructions and memory do different jobs. The help article How does Claude's memory work? explains that memory saves topics as you chat, works with Cowork only in cloud sessions, and that local sessions do not use memory. Instructions apply whether a session is local or cloud, and they only change when you, or Claude updating folder instructions, change them.

Note that Anthropic's onboarding tutorial was written before Cowork gained memory, so its line that Cowork "doesn't remember between sessions the way chat does" is now only true for local sessions.

Writing instructions that work

  1. One rule per line. Short sentences are easier to follow and to check.
  2. Say what to do, not just what to avoid. "Save as a new file named with today's date" beats "don't overwrite".
  3. Include thresholds. "Ask before any refund over £100" is clearer than "be careful with refunds".
  4. Name real places. The actual sheet, folder or label name.
  5. Test it. Ask Claude what it knows about how you work, then run a small task and see whether it follows the rules.
  6. Review monthly. Delete rules you no longer need; long lists dilute the important ones.

Worked example

Example: Nina sells handmade candles online and uses Cowork for order admin.

  1. Global instructions (Settings > Cowork): "Use UK English. Never send emails; leave drafts. Ask before deleting anything. Save documents as .docx."
  2. Project "Orders", instructions box: "I run a two-person candle shop. Orders live in the sheet 'Orders 2026'. Customer emails come to Gmail with the label 'Shop'. Delays over 5 days get an apology draft offering free shipping on the next order, which I approve. Output: a short daily summary at the top of the sheet."
  3. File in the folder, notes.md: "This week: lavender out of stock until 28th; tell customers honestly."
  4. Check: she asks, "Tell me what you know about how I work here." Claude lists the rules back. She notices it missed the 5-day threshold and makes that line clearer.
  5. Result: each morning's task follows the same rules without her retyping them, and she updates only notes.md when stock changes.

Is there a course that shows the actual operator rules a real business gives Claude Cowork?

Yes. The Cowork Operator by Asendify documents one shop's real operator rules, connected apps and safeguards. It is independent of Anthropic; the tutorials are free.

Where are global instructions in Cowork?

In Settings > Cowork. Click Edit next to Global Instructions, type and save.

Do project instructions apply to other projects?

No. They carry into tasks started inside that project only. Use global instructions for rules everywhere.

Can Claude change my instructions?

The help centre says Claude can update folder instructions during a session. Global instructions change only when you edit them.

Should I use instructions or memory?

Use instructions for rules you depend on and want to review. Memory is helpful for picking up preferences but only works in cloud sessions.

How long should instructions be?

Short enough to read in a minute. Put changing details in a notes file in the folder instead.
