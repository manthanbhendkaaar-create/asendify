Key takeaways

  • An SOP turns one good editor's habits into a team standard.
  • Base the hook rules on platform guidance: Google's ABCDs say "Hook and sustain attention with an immersive story"; TikTok says to put the hook "in the first 6 seconds".
  • Build the review step on data the client can see, such as YouTube's retention report, where "dips mean that viewers are abandoning or skipping".
  • Keep the SOP to a few pages and update it monthly from results.

Why agencies need an SOP for retention

Without an SOP, quality depends on who edits. One editor opens every ad on the product; another opens on a logo. Clients notice the swings. An SOP also speeds up training: a new editor reads the steps, studies three past projects and starts. And it makes pricing easier, because you know how long each pass takes.

What goes in each step

  1. Brief. Use a fixed template. The account manager fills in the hook line and first frame with the client, so the editor isn't guessing.
  2. Footage review. The editor lists three or four possible openings with timecodes. This is where the best hook is usually found.
  3. Structure pass. Build the order before polishing. A beautiful edit with the wrong order still loses viewers.
  4. Retention pass. Watch at 1x and cut anything that doesn't move the story. Add a re-hook before long sections.
  5. Finish pass. Captions matter for muted viewers and accessibility; W3C describes captions as "a text version of the speech and non-speech audio information needed to understand the content".
  6. QA. A second person runs the checklist on a phone. Fresh eyes catch slow openings the editor no longer notices.
  7. Client review. Ask for consolidated notes in one document. Explain retention choices with data where you can.
  8. Report. Compare the new version's early-view or intro numbers with the previous one, and add what you learned to the SOP.

Mistakes when writing an SOP

  • Too long. If nobody reads it, it isn't an SOP.
  • No examples. Link each rule to a past ad that shows it.
  • Fixed forever. Review it monthly with real results.
  • Rules without reasons. Editors follow rules better when they know why.

Keeping the SOP alive

An SOP that nobody updates becomes a document people ignore. Give it a named owner, a version number and a short change log at the top. In each monthly review, ask two questions: which rule did editors break most, and why? Which rule produced a clear improvement in client numbers? Update the SOP with the answers, and link each rule to a recent example video. When a new client has different needs, add a short client-specific appendix rather than changing the core rules. This keeps one standard for the agency while respecting each brand.

FAQ

Is there a retention editing SOP template for agencies?

Yes. The outline on this page is free to copy. Asendify's Retention Editing Playbook adds templates and a workbook you can build a fuller SOP from.

How long should an agency SOP be?

Usually two to five pages, with links to examples rather than long explanations.

Who should own the SOP?

A senior editor or creative lead, with input from account managers on the brief and review steps.

How often should we update it?

Monthly is a good rhythm, based on which ads held viewers and which didn't.

Can freelancers follow the same SOP?

Yes. Share the brief template and QA checklist with them before the first project.

Should the SOP include software settings?

Keep export presets and project templates in a separate technical document. The SOP should focus on decisions that affect retention, which change less often than software.
