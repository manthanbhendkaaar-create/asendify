Can Claude Cowork create and edit Excel, PowerPoint and Word files?

By the Asendify editorial team, led by Manthan Bhendkar · 6 min read · Published 20 November 2026 · Last updated 20 November 2026

Disclosure: Asendify publishes this page and makes some of the options mentioned here; ours are named as ours. Every option is described from its own official page, and prices and features can change, so check before you buy.

Yes. Claude Cowork can create Excel spreadsheets with working formulas, PowerPoint presentations and formatted Word documents, as well as PDFs, and on the desktop app it can read and write files in folders you connect. Finished files appear in your session to preview and download. Cowork needs a paid Claude plan, and permanently deleting files always needs your "Allow".

Key takeaways

  • Anthropic's Cowork documentation lists "Excel spreadsheets with functional formulas, PowerPoint presentations, and formatted documents" among its outputs.
  • Claude's file creation feature covers .xlsx, .pptx, .docx and PDF, with a 30MB limit per file for uploads and downloads.
  • On the desktop app, Cowork reads and writes local files "without manual uploads or downloads", but only in folders you connect.
  • Spreadsheets and slides can be edited further in Claude for Excel and PowerPoint, according to Anthropic's help centre.
  • File work uses more of your plan than chat, so batch related jobs into one task.

What Cowork can produce

Anthropic's Cowork overview describes Cowork as an agentic workspace that "uses the same agentic architecture that powers Claude Code", accessible in Claude Desktop without a terminal. Among its key capabilities it lists "Professional outputs — Creates polished deliverables including Excel spreadsheets with functional formulas, PowerPoint presentations, and formatted documents."

The help article Create and edit files with Claude is more specific about formats:

The Cowork product page also lists Excel (.xlsx, .xls, .xlsm) and PowerPoint (.pptx, .ppt) among the file types Cowork can work with, and gives examples such as a weekly marketing readout where "Claude pulls the numbers, compares them to the period before, and builds the deck", and month-end work that returns "a working spreadsheet with variances flagged".

How it works with your own files

Anthropic's Get started with Claude Cowork explains the rules:

  • Local access needs the desktop app. On desktop, Claude can read and write local files without manual uploads, but only in folders you have connected.
  • Isolated sessions. Sessions run in an isolated environment, which protects your computer but does not limit what Claude can do with the access you grant.
  • Deletion needs permission. Claude must ask, and you must select "Allow", before it permanently deletes any file.
  • Outputs. Finished files are delivered to your session to preview and download. If something is not where you expected, check folder permissions and the output location Claude named.
  • Further editing. Spreadsheets and slides can be refined in Claude for Excel and PowerPoint.

The help article also warns about prompt injection: a malicious file or website could try to trick Claude into running untrusted code or leaking data, which is why Anthropic recommends watching what Claude does with sensitive files.

Good prompts for file work

  • "Read the three supplier CSVs in this folder and build one Excel workbook: a tab per supplier, a summary tab with SUMIFS totals by month, and conditional formatting on anything over budget."
  • "Turn this Word report into a 10-slide PowerPoint deck for the board. One message per slide, speaker notes underneath, our logo from /brand."
  • "Draft a two-page .docx letter to each client in clients.xlsx, using their name and outstanding balance. Save drafts only, do not send."
  • "Check this spreadsheet's formulas and list any cells where totals do not add up."

Tips that save rework: name the output file and folder, say which tabs or slides you want, ask for formulas rather than pasted values, and ask Claude to list what it changed.

Worked example

Example: Aisha runs a small events company and uses Cowork on a Pro plan with the desktop app.

  1. Set-up: she connects one folder, "Cowork - Finance", containing 12 monthly bank exports (CSV) and last year's budget (.xlsx).
  2. Task: "Build budget-vs-actual-2026.xlsx with one tab per month, a summary tab using formulas, and flag any category more than 10% over budget. Then make a 6-slide .pptx summary for my accountant."
  3. What happens: Cowork reads the files in the folder, builds the workbook with live SUMIFS formulas, and creates the deck. Both appear in her session and in the folder.
  4. Checking: she spot-checks three months against her bank app. One category is wrong because a refund was coded as income; she asks Claude to fix the rule and rebuild, then checks the same three months again before sending anything.
  5. Safeguard: her global instruction says "Ask before deleting or overwriting any file", so Claude saves a new version instead of overwriting last year's budget.

Common mistakes

  • Expecting folder access on the web app. Local folders need the desktop app.
  • Connecting your whole drive. Connect a dedicated working folder.
  • Accepting numbers without checking. Spot-check totals against source data.
  • Pasted values instead of formulas. Ask for formulas so the workbook stays live.
  • Huge files. The per-file limit is 30MB; split large exports.
  • Forgetting usage. Several big file jobs in one day can use a lot of your plan; check Settings > Usage.

Can Claude Cowork edit an existing Excel file?

It can read and write files in folders you connect on the desktop app. Ask it to save a new version if you want to keep the original.

Do Cowork spreadsheets have real formulas?

Anthropic says Cowork creates Excel spreadsheets "with functional formulas". Ask for formulas explicitly so values are not pasted in.

What is the file size limit?

30MB per file for uploads and downloads, according to Anthropic's help centre.

Can Cowork delete my files?
