How do I create skills in Claude Cowork?

By Manthan Bhendkar · 6 min read · Published 13 November 2026 · Last updated 13 November 2026

To create a skill for Claude Cowork, make a folder containing a skill.md file that starts with a short YAML header giving the skill a name and a description, followed by plain instructions. Zip the folder, upload it to Claude, and turn it on under Customize > Skills. Claude then loads the skill automatically whenever a task matches its description.

Key takeaways

  • A skill is a folder of instructions, and optionally scripts and reference files, that teaches Claude one repeatable workflow.
  • The only required file is skill.md, with a name (up to 64 characters) and a description (up to 200 characters) at the top.
  • The description matters most, because Claude uses it to decide when to use the skill.
  • Skills need code execution turned on, and are available on Free, Pro, Max, Ultra, Team and Enterprise plans.
  • Start with simple written instructions, test with real prompts, and add scripts later.

What a skill is

Anthropic's help article What are skills? defines them as "folders of instructions, scripts, and resources that Claude loads dynamically". Some are made by Anthropic, such as the skills behind its Excel, Word, PowerPoint and PDF handling. Others are custom skills you or your organisation build, for example to apply a style guide or follow an email template.

Claude does not read every skill in full all the time. Anthropic describes a progressive disclosure model: Claude reviews the available skills when given a task, decides which are relevant, and loads only what it needs. This keeps its working memory free for the task itself.

In Cowork, skills can also arrive inside plugins. Anthropic's Cowork getting started guide says plugins bundle "skills, connectors, and sub-agents into a single package", and that a plugin you add is saved to your account and also works in chat and Claude Code.

Step by step: build your first skill

  1. Pick one workflow. Anthropic recommends keeping each skill focused on one task. "Write our weekly client update" is a good skill. "Do all my admin" is not.
  2. Create a folder with a short, lowercase name, such as weekly-client-update.
  3. Create skill.md inside it. At the top, add the YAML header with a name and a description. Below it, write the instructions as you would brief a new colleague.
  4. Write a specific description. Say what the skill does and when to use it, for example: "Drafts the Friday client status email from meeting notes. Use when asked for a client update or weekly summary."
  5. Add examples. Include one example input and the output you want. Anthropic suggests example inputs and outputs as a best practice.
  6. Zip the folder so that the skill folder is the root of the archive, not loose files at the top level.
  7. Upload it to Claude, then enable it under Customize > Skills.
  8. Test it. Try several prompts that should trigger the skill and check that Claude uses it.

Anthropic notes that skills require code execution to be enabled, so check that setting if a skill does not appear to load.

What to put in the instructions

A skill is a written brief. The clearer the brief, the more consistent the output. A useful structure:

  • Purpose: one sentence on what the skill produces.
  • Inputs: where the information comes from, such as a folder of notes or a connector.
  • Steps: the order Claude should follow.
  • Format: headings, length, tone and file type.
  • Rules: what never to do, such as "never send; always save a draft".
  • Example: one good finished output.

Anthropic's best practices for getting started with Cowork make the same point about context: the gap between mediocre and great results is usually whether you provide enough rich context for Claude to work with.

Example: a skill for weekly client updates

Example: Ana runs a small marketing agency with eight retainer clients. Each Friday she writes a status email per client.

nameweekly-client-update
description"Drafts the Friday status email for a retainer client from that week's notes. Use for client updates or weekly summaries." (120 characters)
InputsThe client's notes folder
FormatGreeting, three wins, one risk, next week's plan, under 180 words, friendly and plain
RulesNever send; save as a draft. Never mention other clients.
ExampleOne past email she was happy with

Her first test triggered the skill for "write this week's update for Bloom Café" but not for "summarise Bloom's week". She added "summary" to the description and it triggered for both. She then paired the skill with a scheduled task so drafts are ready every Friday morning. Her own estimate is that drafting time fell from about an hour to 20 minutes of checking; this is her estimate, not a measured result.

Safety tips

Anthropic's guidance warns against hardcoding API keys or passwords in skills, and advises reviewing any downloaded skill before enabling it. Be careful with scripts you did not write yourself. On Enterprise plans, organisations can turn on skill scanning to check uploaded skills and plugins for malicious content.

FAQ

Do I need to code to create a Claude skill?

No. The only required file is skill.md, written in plain language with a short header. Scripts are optional and can be added later.

Where do I turn on a skill?

After uploading it, enable it under Customize > Skills. Anthropic notes that code execution must also be enabled.

How long can a skill description be?

Up to 200 characters. The name can be up to 64 characters.

Can I share a skill with my team?

Team and Enterprise owners can provision skills for their whole organisation. Individuals can share the zipped folder for others to upload.

Why is Claude not using my skill?

Usually the description does not match how people phrase the request. Rewrite it with the words you actually use and test again.
