Can Claude Cowork use a web browser, and should you use the built-in browser or Claude in Chrome?

By Manthan Bhendkar · 6 min read · Published 19 November 2026 · Last updated 19 November 2026

Disclosure: Asendify publishes this page and makes some of the options mentioned here; ours are named as ours. Every option is described from its own official page, and prices and features can change, so check before you buy.

Yes. Claude Cowork can browse the web in two ways: its own built-in browser, which opens in a side panel of the Claude Desktop app and is separate from your browser, or Claude in Chrome, an extension that works inside your own Chrome with the accounts you are already signed in to. Use the built-in browser to hand off web tasks without touching your tabs; use Claude in Chrome for pages you already have open.

Key takeaways

  • Anthropic announced Cowork's built-in browser on 26 August 2026. It is available on Pro, Max, Ultra, Team and Enterprise plans in Claude Desktop for macOS, Windows and Linux (beta).
  • The built-in browser needs Claude Desktop open and online, even when you steer the task from web or mobile.
  • Claude in Chrome works only in Google Chrome, not other Chromium browsers or mobile, and uses your existing logins.
  • If you already use Claude in Chrome it stays the default; change it under Settings > Cowork > Preferred browser.
  • Both carry prompt injection risk. Anthropic says safeguards "meaningfully reduce the risk but can't eliminate it" and advises against using either for financial accounts, medical information or other people's personal data.

What the built-in browser can do

Anthropic's announcement, Claude gets its own browser in Cowork, gives examples: gathering research for a report, collecting monthly invoices from a vendor portal, filling in a form, pulling numbers from a dashboard, and working through a portal that has no connector. The help article says Claude opens sites, reads pages, clicks, types and fills forms while you watch in the side panel.

On privacy, the announcement says: "Claude never sees your tabs, bookmarks, or passwords." Importing logins is optional and per site. Banking, email and single sign-on sites are unchecked by default. Import works from Chrome, Edge and Firefox on macOS and from Firefox on Windows and Linux; Safari is not supported.

What Claude in Chrome adds

The Claude in Chrome guide describes it as "a browser extension that allows Claude to read, click, and navigate websites alongside you". It can be used from the Chrome side panel, from Cowork or from Claude Code. Notable features include multi-tab work in a tab group, built-in knowledge of Slack, Google Calendar, Gmail, Google Docs and GitHub, and 1Password sign-in in beta on macOS, where Claude never sees the password.

To connect it to Claude Desktop, the guide says to go to Settings > Customize > Connectors, click Configure and toggle it on. It is off by default in each conversation. On Enterprise, an owner must enable it.

How Cowork chooses

The help article explains the default: if you already use Claude in Chrome, it stays your default; otherwise Cowork uses the built-in browser. You can set your choice under Settings > Cowork > Preferred browser. If the preferred browser is unavailable, Claude tells you and uses the other one. If you ask for a specific browser by name and it is unavailable, Claude asks before switching.

Safety: what Anthropic says

Both browsers use the same protections:

  • Claude asks permission before acting on a site for the first time.
  • High-risk sites are blocked.
  • Each action is checked against what you asked for.

But Anthropic is clear that prompt injection, where hidden instructions on a web page try to redirect Claude, can still happen. Its advice is to start with sites you trust, and not to use either browser for financial accounts, medical information or other people's personal data. The Claude in Chrome guide says the product, though improved with safety classifiers, "is still risky".

For Team and Enterprise, owners control whether the built-in browser is available, and admins can restrict sites for Claude in Chrome with allowlists and blocklists.

Worked example

Example: Priya runs a small online shop and spends an hour each month downloading invoices from three supplier portals and copying totals into a spreadsheet.

  1. Setup: she keeps Claude Desktop open on her Mac and leaves the preferred browser as the built-in browser, because she does not want Claude in her personal Chrome.
  2. Logins: on first use she imports cookies for the three supplier sites only, leaving email and banking unchecked.
  3. Task: in Cowork she asks Claude to download last month's invoices from the three portals into a folder and add each total to her spreadsheet. Claude asks permission before acting on each site the first time.
  4. Watching: she keeps an eye on the side panel for the first run and checks the totals against the PDFs.
  5. Later: when she needs Claude to tidy a Google Sheet already open in Chrome, she asks for Claude in Chrome by name for that task instead.

FAQ

Yes. The Cowork Operator by Asendify documents one shop's real rules, connected apps, scheduled tasks and safeguards. It is independent of Anthropic; Anthropic's help articles are free.

Does the built-in browser see my passwords?

No. Anthropic says Claude never sees your tabs, bookmarks or passwords unless you import a site's login.

Can I use Claude in Chrome with Edge or Brave?

No. Anthropic says Claude in Chrome is not supported on other Chromium-based browsers or on mobile.

Does the built-in browser work when my computer is off?

No. Claude Desktop must be open and online for Claude to use it, even if you started the task from web or mobile.

How do I switch between the two browsers?

Set Settings > Cowork > Preferred browser, or ask for a specific browser by name in your task.

Is it safe to let Claude log into websites?

Start with sites you trust. Anthropic warns prompt injection can still happen and advises against using either browser for financial or medical accounts.
