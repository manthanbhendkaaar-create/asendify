What are Claude Cowork plugins, and how do you install one?

By Manthan Bhendkar · 6 min read · Published 19 November 2026 · Last updated 19 November 2026

Disclosure: Asendify publishes this page and makes some of the options mentioned here; ours are named as ours. Every option is described from its own official page, and prices and features can change, so check before you buy.

A Claude Cowork plugin is one installable package that bundles skills, connectors, sub-agents and sometimes hooks around a single job, such as sales prep or contract review, so Claude arrives already set up for it. You install one from Customize > Plugins, either from a marketplace or from a file, and can switch its parts on or off afterwards.

Key takeaways

  • Anthropic calls a plugin "a pre-built toolkit for a role or workflow". It can hold skills, MCP connectors, sub-agents, slash commands and hooks.
  • Plugins are available on Pro, Max, Ultra, Team and Enterprise, according to Anthropic's help centre.
  • Install from Customize > Plugins. Anthropic's Knowledge Work marketplace is added by default, and a GitHub repository can act as your own marketplace.
  • Hooks, sub-agents and local MCP servers run only in Cowork and Claude Code, not in normal chat.
  • Install only from sources you trust: a local MCP server runs on your computer with the same permissions as any other program.

What a plugin contains

Anthropic's Cowork documentation, Install plugins, says a plugin's manifest can declare any combination of four parts:

ComponentWhat it addsRuns in normal chat?
SkillsReusable instructions that teach Claude a workflowYes
ConnectorsMCP servers that give Claude access to an outside serviceYes (remote)
Agents (sub-agents)Specialised helpers Claude can hand work toNo, Cowork and Code only
HooksScripts that run at set points in a sessionNo, Cowork and Code only

Anthropic's product guide, Extending Claude Cowork with plugins, explains why this matters: with a plugin, "Claude knows the vocabulary, the steps, and the outputs your workflow expects," so you stop re-explaining the same process every session. Its example is a customer success "Renewal prep" plugin: typing /prep-renewal Acme Corp pulls the account from Salesforce, checks support tickets, reviews recent call notes and saves a briefing to a Google Doc.

Plans and where plugins work

The help article Use plugins in Claude lists Pro, Max, Ultra, Team and Enterprise. Plugins are saved to your account, so the same plugins appear in web chat, the Chat tab of the desktop app and Cowork, and sync to Claude Code (v2.1.273 or later) when you sign in with the same account. Skills and commands work everywhere; hooks, sub-agents and local MCP servers run only in Cowork and Claude Code, so they show greyed out in chat.

Anthropic's library covers functions such as sales, finance, legal, marketing, HR, engineering, design, operations and data analysis, and some plugins are built by partners.

How to install a plugin

From Anthropic's documentation:

  1. Open Customize in the sidebar, then Plugins (in the desktop app, open the Cowork tab first).
  2. Browse the marketplace and pick a plugin. The default is Anthropic's Knowledge Work catalogue; you can add others, such as Financial Services, Legal or Life Sciences.
  3. Click Install or Add. If the plugin includes a connector that needs a login, you are asked to sign in.
  4. Open the installed plugin and review its skills, connectors, agents and hooks. Turn off any part you do not need.

To use it, type / or click + in a chat or Cowork task to see its skills. In Cowork you can call a specific command as /plugin-name:command.

You can also upload a plugin file you built, or add a Git repository as a marketplace: paste a https://github.com/owner/repo URL (public GitLab and Bitbucket repositories also work) and click Update later to pull new versions.

Customising and building your own

In Cowork, open an installed plugin and click Customize. This starts a Cowork task in which Claude helps adapt the plugin's skills and connectors to how you work. To build from scratch, Anthropic offers a Plugin Create plugin that walks you through it, or you can start from one of its templates.

The product guide's advice is to start small: one skill for your most repetitive task, then add a sub-agent only when a job needs its own separate context. It also says to skip plugins for one-off questions; they pay off on repeated work that spans several tools.

Team and Enterprise controls

  • Owners turn on skill and plugin sharing in the admin Policy settings. Shared plugins are view-only for the people you share them with and update automatically.
  • Admins can publish plugins to the organisation's library as available, installed by default, or required. Required plugins cannot be switched off, even in Claude Code.
  • On Enterprise, admins can restrict which marketplaces are allowed, tailor the catalogue by group, or disable local MCP servers entirely. With skill scanning on, malicious plugins are blocked and risky ones show a caution banner.
  • Plugins installed from a marketplace cannot be re-shared.

Safety checks before you install

  • Install only from trusted sources. A local MCP server runs on your computer with the same permissions as any other program.
  • Read what each plugin's connectors can do, and keep write actions such as sending or deleting behind approval.
  • Review plugins someone shares with you before enabling them.
  • If you edit a plugin's files locally, Cowork warns you before an update would overwrite your changes.
  • Custom connectors behind a private network or firewall will not work in Cowork without extra network setup, because connectors reach services through Anthropic's cloud.

Worked example

Example: a three-person bookkeeping firm sends every client the same month-end pack.

  • They install one plugin from their own private GitHub repository containing a "month-end pack" skill (which reports to build and in what order), a Google Drive connector and a short hook that saves each pack into the client's folder.
  • In Cowork, a bookkeeper types /month-end:pack Client A and reviews the draft before anything is sent.
  • When the checklist changes, the partner edits the skill in the repository and each person clicks Update on the marketplace.

The firm now writes its process down once instead of in every prompt, and a new hire gets the same steps on day one.

What is the difference between a skill and a plugin?

A skill is one set of instructions for a workflow. A plugin is a package that can bundle several skills with connectors, sub-agents and hooks, installed in one step.

Are Cowork plugins free?

Anthropic's help centre lists plugins as part of the Pro, Max, Ultra, Team and Enterprise plans and does not mention a separate fee for its own marketplace plugins. Partner connectors inside a plugin may need an account with that service.

Can I make my own plugin?

Yes. Use Anthropic's Plugin Create plugin or a template, then upload the file or host it in a Git repository that you add as a marketplace.

Do plugins work in normal Claude chat?

Partly. Skills and commands work in chat, but hooks, sub-agents and local MCP servers run only in Cowork and Claude Code.

How do I remove a plugin?

Open it under Customize > Plugins and click Uninstall. Plugins your organisation requires can only be removed by an admin.
