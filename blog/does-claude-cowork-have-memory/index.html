Does Claude Cowork have memory, and what does it remember between tasks?

By Manthan Bhendkar · 6 min read · Published 20 November 2026 · Last updated 20 November 2026

Disclosure: Asendify publishes this page and makes some of the options mentioned here; ours are named as ours. Every option is described from its own official page, and prices and features can change, so check before you buy.

Yes. Since 25 August 2026, Claude Cowork shares one memory with Claude chat, so preferences and project details you mention in a chat carry into Cowork tasks and back again. Memory only works in cloud Cowork sessions; local sessions do not use it. You can view, edit, pause or reset what Claude remembers under Settings > Memory.

Key takeaways

  • Before August 2026, Cowork had no memory: details from chat did not carry over and you had to re-brief it.
  • Memory is now saved as short "topics" during a conversation, not summarised after it ends.
  • It is on by default for Free, Pro, Max and Ultra, and off for Team and Enterprise users until an owner enables it.
  • Health, religion, politics and similar sensitive topics are not saved unless you switch that on; ID numbers, criminal history, financial account numbers and immigration status are never saved.
  • Each Claude project keeps its own separate memory space.

What changed in August 2026

Anthropic's announcement, Claude's memory works everywhere, and you decide what's in it, put it plainly: "Starting today, the memory you use in chat is the same as in Claude Cowork." It also said Cowork had memory for the first time and that Claude "now adds topics to memory as you chat, instead of summarizing conversations after they end."

TechCrunch's Sarah Perez covered the change the same day, noting that before the update, users moving from research in chat to action in Cowork had to start over and re-enter project details. Anthropic's examples included drafting a manager update or a conference agenda where Cowork already knows the headcount, city and speakers from earlier chats.

How Cowork memory works

The help article How does Claude's memory work? gives the detail:

  • Topics. Claude saves individual topics as you chat, either on its own or when you say "remember this". You see them listed under Topics in Settings > Memory.
  • Cloud only for Cowork. Memory works across chat and Cowork only when Cowork runs in the cloud. Locally run Cowork sessions do not use memory.
  • Projects are separate. Each project has its own memory space and summary, kept apart from other projects and from non-project chats.
  • Incognito chats are not saved to memory, and Claude will not search them later.

When sensitive-topic saving is on, Claude shows a notice each time it saves one. Turning the setting off, or declining a notice, removes sensitive items already saved.

Controls you have

  • View and edit. Settings > Memory lists every topic. Open one to read it, edit it or delete it. You can also tell Claude in chat to change or forget something; the change applies from your next conversation.
  • Pause. Claude keeps existing memory but stops using it and stops adding to it. Conversations during the pause are not added later.
  • Reset. Permanently deletes all memories, including project memories. It cannot be undone.
  • Deleting a chat does not remove memory topics created from it, so delete the topic itself if needed.

Team and Enterprise

On Team and Enterprise, owners turn memory on in Organization settings > Capabilities, and each user then chooses whether to use it. Owners cannot view or edit individual users' memories. Turning memory off for the whole organisation permanently deletes everyone's memory data. The help article also says memory is unavailable to organisations with HIPAA, public-sector or custom data retention agreements. Anthropic's announcement adds that memory is on by default for members of most Team and Enterprise organisations created on or after 31 October 2026, unless a member had already turned it off.

Worked example

Example: Sam runs a three-person design studio and uses Cowork on a Pro plan.

  1. Monday, in chat: Sam explains that client reports always use British spelling, a one-page summary first, and that the studio's financial year starts in April.
  2. Claude saves topics: "Report style: UK spelling, one-page summary first" and "Financial year starts April". Sam checks Settings > Memory and sees both.
  3. Wednesday, in Cowork (cloud session): Sam asks Cowork to build the quarterly client report from a shared spreadsheet. It uses UK spelling, leads with a one-page summary and labels the quarter correctly, without being told again.
  4. A correction: the studio changes to a two-page summary. Sam edits the topic once, and every later task uses the new rule.
  5. A local task: Sam runs a local session to tidy a folder on the laptop. That session does not use memory, so Sam includes the folder naming rule in the prompt.

Common mistakes with Cowork memory

  • Assuming a local task remembers. Local sessions do not use memory, so put key rules in the prompt, in folder instructions or in global instructions (Settings > Cowork).
  • Storing rules only in memory. Memory topics are short and Claude decides what to save. For rules a business depends on, such as approval limits or tone for clients, write them down as instructions or a skill you can review.
  • Forgetting projects are separate. Something Claude learned in one project will not appear in another, which is useful for client separation but surprising if you expect it everywhere.
  • Not checking the Topics list. A wrong topic keeps being applied until you fix it. A two-minute look at Settings > Memory each week catches mistakes early.

FAQ

Is there a course that shows how a real business writes the standing rules Cowork follows?

Yes. The Cowork Operator by Asendify documents one shop's real operator rules, connected apps and safeguards. It is independent of Anthropic; the help articles are free.

Does Cowork remember things in local sessions?

No. Anthropic's help centre says locally run Cowork sessions do not use memory; only cloud sessions do.

Can I stop Cowork remembering something?

Yes. Delete the topic in Settings > Memory, ask Claude to forget it, or pause memory entirely.

Is memory on for Team plans?

Not automatically for older organisations. An owner enables it, then each user turns it on.

Does deleting a chat delete the memory from it?

No. In the new memory system you must delete the topic itself.

Do projects share memory?

No. Each project has its own memory space, separate from other projects and from ordinary chats.
