What is computer use in Claude Cowork, and how do you turn it on?

By Manthan Bhendkar · 6 min read · Published 20 November 2026 · Last updated 20 November 2026

Disclosure: Asendify publishes this page and makes some of the options mentioned here; ours are named as ours. Every option is described from its own official page, and prices and features can change, so check before you buy.

Computer use is a Claude Cowork feature that lets Claude click, type and open apps on your screen when it has no connector or browser route for a task. You turn it on in Claude Desktop under Settings > Capabilities with the "Enable computer use" toggle, then approve each app the first time Claude asks. It is a beta for Pro and Max on macOS and Windows.

Key takeaways

  • Claude tries connectors first, then a browser, and only uses your screen directly as a last resort, because it is the slowest and most error-prone route.
  • Anthropic's help centre lists computer use as a beta for Pro and Max on macOS and Windows; it launched as a Mac-only research preview in March 2026.
  • Claude asks before it touches each app, and some apps (investment, trading and crypto platforms) are blocked by default.
  • There is no sandbox between Claude and your apps, so Anthropic advises against using it with banking, healthcare or government apps.
  • Your computer must be awake and Claude Desktop open for computer use to work, even from a cloud session.

What computer use actually does

Anthropic's help article Let Claude use your computer in Cowork describes it simply: when computer use is enabled and Claude has no connector or tool for a task, it can click, type and open apps on your screen. It can work in your browser, open files and run developer tools, with no setup beyond switching it on. It works in both Cowork and Claude Code inside the Claude Desktop app.

The important detail is the order Claude works in. In Cowork it tries:

  1. Connectors such as Gmail, Google Drive, Microsoft 365 or Slack.
  2. A browser, either Cowork's built-in browser or Claude in Chrome.
  3. Your screen, by taking screenshots and clicking, as a last resort.

So computer use is a fallback for apps with no connector, not the main way Cowork gets work done.

When it arrived

Engadget's Anna Washenko reported on 23 March 2026 that Claude Code and Cowork could now carry out tasks on a user's computer, including opening files, using a browser and running developer tools, as a research preview for Pro and Max subscribers starting on macOS. MacRumors' Tim Hardwick described the same launch with Anthropic's demo: asking Claude, while away from the Mac, to export a pitch deck as a PDF and attach it to a meeting invite. He quoted Anthropic's own caution: "Computer use is still early compared to Claude's ability to code or interact with text."

Since then the help centre has added Windows. Check the article before relying on Team or Enterprise access: one section mentions Team in beta while another says Team and Enterprise plans do not have computer use yet.

The practical lesson: connect the tools you use most. Every task that can go through a connector avoids the slow, screenshot-based route.

How to turn it on

From the help article:

  1. Update Claude Desktop.
  2. Open Settings > Capabilities (or Settings > System, under This computer).
  3. Turn on Enable computer use.
  4. Start a Cowork or Claude Code session.
  5. Approve the permission prompt when Claude asks to use an app.

On macOS 15 or later, Claude can work in background windows without taking over your pointer or keyboard. It waits if you are typing and asks the first time a task needs the full screen in each session. You can switch to full control in the setting for how Claude uses allowed apps.

Permissions and privacy

  • Per-app approval. Claude asks before it accesses each app.
  • Blocked by default. Investment, trading and cryptocurrency platforms are blocked out of the box, and you can add your own apps to a blocklist so requests are denied automatically.
  • Screenshots. Claude navigates by taking screenshots, so it can see anything visible on screen. Close sensitive files and apps first.
  • Cross-app effects. A link clicked in one app may open in another, such as Chrome, even if Claude is not allowed to use that app.

Anthropic's separate guide, Use Cowork safely, repeats that computer use runs with no sandbox between Claude and your screen and recommends blocking sensitive apps such as banking or healthcare portals. Permanent file deletion still needs your explicit "Allow" in every approval mode.

Limits worth planning around

  • Your computer must be awake and Claude Desktop open.
  • Complex multi-step tasks may need a second attempt.
  • Screen interaction is slower than connectors.
  • It is a beta, so behaviour can change.
  • You remain responsible for what Claude does on your behalf, according to the safety guide.

Worked example

Example: Priya runs a small bookkeeping firm. Her client invoices live in a desktop accounting app with no Claude connector, but her email is Gmail.

  1. Setup: she connects Gmail as a connector and turns on computer use. She creates a folder called "Cowork exports" and connects only that folder.
  2. Task: "Export last month's unpaid invoices from the accounting app as PDFs into Cowork exports, then draft a reminder email for each client in Gmail."
  3. What happens: Claude asks permission to use the accounting app. Priya approves it. Claude uses the screen to run the export (the slow part), then switches to the Gmail connector to draft the emails (the fast part).
  4. Safety choices: she keeps the approval mode on manual for this task because it touches client data, keeps her banking app on the blocklist, and reviews the drafts before sending anything.
  5. Result: the export takes a couple of attempts the first time. She notes the steps in a reusable instruction so the next run is smoother.

Is there a course that shows how a real business sets up Cowork safeguards like app permissions?

Which plans get computer use in Cowork?

Anthropic's help centre lists it as a beta for Pro and Max on macOS and Windows. Team and Enterprise access is described inconsistently, so check the current article.

Does computer use work when my laptop is closed?

No. Your computer must be awake and Claude Desktop open, even if the session runs in the cloud.

Can Claude use my banking app?

Investment, trading and crypto apps are blocked by default, and Anthropic advises against using computer use with banking, healthcare or government apps.

Why is computer use slow?

It works from screenshots and clicks. Connectors and the browser are faster, so Claude uses them first.

Can I stop Claude mid-task?

Yes. Anthropic says you can stop it at any time, and it asks before accessing any new app.
