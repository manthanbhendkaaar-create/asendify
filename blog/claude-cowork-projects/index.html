What are projects in Claude Cowork, and how do you set one up?

By Manthan Bhendkar · 5 min read · Published 19 November 2026 · Last updated 19 November 2026

Disclosure: Asendify publishes this page and makes some of the options mentioned here; ours are named as ours. Every option is described from its own official page, and prices and features can change, so check before you buy.

A project in Claude Cowork is a separate workspace for one area of work, such as a client, a shop or your bookkeeping, that keeps its own folders, standing instructions, links, memory and scheduled tasks. You create one from Projects in the left sidebar, and every task you start inside it begins with that setup already loaded, so you stop repeating the same context.

Key takeaways

  • Anthropic's help centre says each project has "its own files, context, instructions, and memory", and can hold project-specific scheduled tasks.
  • You can start from scratch, import an existing Claude chat project, or point a project at a folder you already use.
  • Memory is on for Cowork projects and does not carry over between projects. You can also stop a project using your account-wide memory.
  • Local files and folders stay on your computer; Claude reads individual files up to 50 MB.
  • Sharing a project with "Can view" or "Can edit" access is available on Team and Enterprise plans, where the newer unified experience is on.

What a project holds

Anthropic's help article Organize your tasks with projects in Claude Cowork and its Cowork documentation, Organize work with projects, describe the same building blocks:

How to create one

From the help article:

  1. Open Projects in the left navigation and click +.
  2. Choose a starting point:
  3. Start from scratch: a new folder with instructions and files.
  4. Import from a Claude project: pick a chat project; Claude copies its files and instructions into a new Cowork project saved to a location you choose. Bulk import is not supported.
  5. Use an existing folder: choose a folder on your computer, name the project and add instructions.
  6. Give it a clear name and description, attach any extra folders or links, and write the standing instructions.

Projects need the latest version of Claude Desktop. When you drag files into a project, single files are copied into its first folder and folders are added as extra project folders.

How memory works in a project

The help article says memory is on for Cowork projects, so Claude can apply what it learned in one task to later tasks in the same project. Memory does not cross between projects. By default a project also shares memory with your non-project chats; to keep it separate, turn off Use account memory under Memory on the project's page. That is worth doing for client work, so details from one client never appear in another's tasks.

Where projects live and who can see them

This is the part that has changed most, and Anthropic's two pages describe different setups:

  • The help centre says projects created in Cowork are saved to your Claude account and available on other devices, that desktop automatically moves older local-folder projects into your account, and that sharing works like chat projects on Team and Enterprise plans.
  • The Cowork documentation describes projects that live only on your computer and are not shared.
  • The help centre explains the gap: on Team and Enterprise plans without the unified Chat and Cowork experience, projects created from local folders stay on the computer and are not saved to your account.

Either way, the folders and files themselves stay on your computer. Archiving a project removes it from your list but does not touch those files.

Projects alongside the rest of Cowork

Anthropic's Get started with Claude Cowork lists projects next to scheduled tasks, plugins, global and folder instructions, and permission modes. A useful way to think about them:

  • Global instructions: how you like everything done.
  • Project instructions: rules for one area of work.
  • Plugins and skills: reusable know-how across projects.
  • Scheduled tasks: the recurring jobs, now attachable to a project.

Projects are currently a Cowork feature; the help article says Claude Code support is planned.

Worked example

Example: a freelance bookkeeper has three clients and wants Cowork to prepare a monthly pack for each without mixing them up.

  • She creates three projects, one per client, each using that client's existing folder on her computer.
  • Each project's instructions name the client's year-end, VAT quarter and the report format they like, plus one shared rule: "Draft only. Never send anything."
  • She turns off Use account memory in each project, so nothing learned about one client leaks into another.
  • In each project she adds a scheduled task for the 3rd of every month: "Read last month's bank export in this folder, categorise transactions using the rules in instructions.md, and draft the monthly summary."
  • After two months, project memory has picked up recurring suppliers for each client, and the drafts need fewer corrections.

The setup takes about half an hour per client once, instead of re-explaining every client's quirks in every task.

FAQ

Is there a course that shows a real business's Cowork setup, including its rules and scheduled tasks?

Yes. The Cowork Operator by Asendify documents one shop's real rules, connected apps, scheduled tasks and safeguards. It is independent of Anthropic; the help centre is the free alternative.

Are Cowork projects the same as Claude chat projects?

The help centre says they work the same way, but Cowork projects can also use local folders and hold scheduled tasks. You can import a chat project into Cowork.

Does Claude remember things between tasks in a project?

Yes. Memory is on for Cowork projects and applies within that project only.

Can I share a Cowork project with my team?

On Team and Enterprise plans with the unified experience, yes, with Can view or Can edit access. Local-only projects cannot be shared.

What happens to my files if I archive a project?

Nothing. Archiving removes the project from your list; the folders and files on your computer stay where they are.

Is there a file size limit?

Anthropic's documentation says Claude reads individual files up to 50 MB.
