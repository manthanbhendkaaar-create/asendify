What are Claude connectors, and how do you use them in Cowork?

By Manthan Bhendkar · 5 min read · Published 18 November 2026 · Last updated 18 November 2026

Disclosure: Asendify publishes this page and makes some of the options mentioned here; ours are named as ours. Every option is described from its own official page, and prices and features can change, so check before you buy.

Claude connectors link Claude to the apps you already use, such as Google Drive, Slack or Linear, so it can find information and take actions there with your own permissions. You add them under Customize > Connectors, sign in to each service, and switch them on per conversation or task. They work in Claude, Cowork, Claude Desktop and the mobile apps.

Key takeaways

  • A connector lets Claude retrieve data from an app and take actions in it, such as searching Drive, sending a Slack message or creating a Linear issue.
  • Claude inherits your permissions in each connected service, so it cannot reach anything you could not access yourself.
  • Many connectors are built on the Model Context Protocol (MCP), an open standard Anthropic released in November 2024.
  • Custom connectors to any remote MCP server are available on all plans; Free users are limited to one.
  • For business use, set write actions such as sending or deleting to "needs approval" until you trust the setup.

What a connector is

Anthropic's help article Use connectors to extend Claude's capabilities describes connectors as a way to let Claude access your apps and services, retrieve your data and take actions in them. Its examples include creating issues in Linear, sending messages in Slack and searching files in Google Drive.

The article says web connectors are available to all users on Claude, Cowork, Claude Desktop and Claude Mobile. That matters for Cowork in particular, because a Cowork task that can read your inbox, update a spreadsheet or post a summary is far more useful than one that only works with files you paste in.

How MCP fits in

Many connectors use the Model Context Protocol. Anthropic's announcement, Introducing the Model Context Protocol, dated 25 November 2024, describes MCP as an open protocol for connecting AI assistants to the systems where data lives, replacing one-off integrations with a shared standard. Data owners run MCP servers; AI applications such as Claude act as clients. The launch listed pre-built servers for Google Drive, Slack, GitHub, Git, Postgres and Puppeteer.

You do not need to understand MCP to use the ready-made connectors. It matters when you want to connect a tool that is not in the directory.

How to add a connector

From the Anthropic help article:

  1. Go to Customize > Connectors, or open the Connectors Directory from a chat.
  2. Choose the connector, read its description and click Connect or Install.
  3. Follow the sign-in steps for that service.
  4. In a chat, click + or type /, open Connectors and switch on the ones you want for that conversation.

On Team and Enterprise plans, an Owner or Primary Owner must enable a connector for the organisation first, then each person signs in individually.

Custom connectors and safety

Anthropic's guide to custom connectors using remote MCP explains that connections come from Anthropic's cloud, not your device, so the server must be reachable over HTTPS on the public internet. It is direct about the risks:

  • Custom connectors are not verified by Anthropic, so connect only to servers you trust.
  • Review the permissions a server asks for and deny anything unnecessary.
  • Malicious servers may use prompt injection to make Claude take unintended actions.
  • Server developers can change how tools behave without notice.
  • Use "Allow always" only for tools you fully trust to run unsupervised.

The main help article adds that Team and Enterprise Owners can set each tool to Always allow, Needs approval or Blocked across the organisation, and that individual users can ask Claude to always check before using a specific tool in chat and Cowork.

Worked example

Example: a two-person online shop wants a Monday morning summary of last week's orders and customer emails.

  • They connect Google Drive (where a weekly order export lands) and their email service from the directory, after checking it is listed.
  • In Cowork, they set the email tools that send or delete messages to "needs approval", so Claude can read and draft but not send on its own.
  • The task: read last week's order export from Drive, scan the support inbox for refund requests and complaints, and draft a one-page summary with three actions.
  • The owner reviews the draft each Monday, approves any replies Claude has drafted, and disconnects nothing until the first month shows the summaries are accurate.

Connecting two services and keeping write actions behind approval gave them a useful weekly report without handing over control of their inbox.

Good habits for business use

  • Connect only the services a task needs, and disconnect the ones you stop using, as Anthropic recommends.
  • Use a separate, limited account for any shared fixed credential, since everyone using that connector on a team plan shares it.
  • Keep a written list of which connectors are on, what each can do, and who approved it.
  • Start every new connector with approval required, then relax it tool by tool.

Is there a course that shows a real business's Cowork setup, including its connected apps?

Yes. The Cowork Operator by Asendify documents one shop's rules, connected apps, scheduled tasks and safeguards. It is independent of Anthropic; Anthropic's help articles are the free alternative.

Can Claude see everything in my connected apps?

No. Claude inherits your permissions, so it can only reach what you can access in that service, and only when the connector is switched on.

Are connectors free?

Directory connectors are available on all plans. Custom remote MCP connectors are available on all plans, with Free users limited to one.

Can I stop Claude from sending emails or deleting files?

Yes. Team and Enterprise Owners can set tools to needs approval or blocked, and users can ask Claude to always check before using a specific tool.

How do I remove a connector?

Remove it under Customize > Connectors, or revoke access in the connected service's security settings.
