Is Claude Cowork available on Windows?

By the Asendify editorial team, led by Manthan Bhendkar · 7 min read · Published 21 November 2026 · Last updated 21 November 2026

Disclosure: Asendify publishes this page and makes some of the options mentioned here; ours are named as ours. Every option is described from its own official page, and prices and features can change, so check before you buy.

Yes. Claude Cowork works on Windows: Anthropic lists Claude Desktop for macOS, Windows and Linux (beta) as available on all paid plans, and local file access, browser use and computer use need the desktop app for macOS or Windows. Sessions themselves run in Anthropic's cloud, so a Windows PC mainly matters when a task touches your own files or browser.

Key takeaways

  • Cowork is available on Windows through the Claude Desktop app, on Pro, Max, Ultra, Team and Enterprise plans. The free plan does not include it.
  • Your sessions run on Anthropic's servers, so work carries on when you close the laptop; the desktop app is needed when Claude must reach a local folder, your browser or your screen.
  • A few small features differ by platform, such as which browsers the built-in browser can import cookies from.
  • Linux desktop support is listed as beta, and Cowork is also rolling out on the web and mobile apps.
  • The set-up is the same on every platform: install or update the app, pick Cowork in the message box, connect one working folder, then describe the outcome you want.

What Anthropic says about platforms

Anthropic's help article Get started with Claude Cowork sets out availability in plain terms. Cowork is for paid plans (Pro, Max, Ultra, Team and Enterprise), and "Claude Desktop for macOS, Windows, and Linux (beta)" is available on all of them, downloaded or updated from claude.com/download. Web and mobile access is listed for Pro, Max, Ultra and Team plans (beta on Team), and for Enterprise when an owner turns it on.

The same article explains why the desktop app still matters even though sessions run in the cloud. Under requirements it says local file access, browser use and computer use need "The Claude Desktop app for macOS or Windows, open and connected", because "these capabilities reach things on your computer". It also notes that sessions keep running when the app is closed or the computer is asleep, but if a task uses local files, your browser or your computer, you should keep the app open.

What is different on Windows

Most of Cowork behaves the same on both desktop systems. The differences Anthropic documents are small:

  • Cookie import for the built-in browser. The Cowork product page says the built-in browser can import cookies to stay signed in from "Chrome, Edge, and Firefox on macOS; Firefox on Windows and Linux". On Windows you can still sign in once inside the built-in browser; you just cannot import Chrome or Edge cookies.
  • Renamed or moved folders. Anthropic's guide Keep a folder connected after it's renamed or moved describes a prompt that finds a moved folder "On a Mac with macOS 14 or later". On Windows, if you rename or move a connected folder, plan to connect it again.
  • Download buttons. The product page leads with a macOS download button, but the help article lists Windows on all paid plans, so use claude.com/download to get the Windows installer.

How to set it up on a Windows PC

  1. Install or update Claude Desktop from claude.com/download and sign in.
  2. Open the message box and choose "Cowork". If you only see one box with no Chat/Cowork switch, you have the newer combined experience and any conversation can take on a Cowork task.
  3. Connect one folder. Create something like C:\Users\you\Documents\Cowork and connect that, not your whole drive.
  4. Pick a permission mode. Anthropic describes Manual (Claude asks before actions), Auto (an automated check reviews actions) and Skip (no checks). Start with Manual while you learn.
  5. Add global instructions such as "Ask before overwriting files" and "Save drafts, never send emails".
  6. Give it a small first task, such as tidying a folder of receipts into a summary spreadsheet, and check the result before you trust bigger jobs.

Worked example

Example: Tom runs a two-person plumbing business and uses a Windows laptop on a Pro plan.

  1. He installs Claude Desktop, chooses Cowork, and connects Documents\Cowork - Admin, which holds 40 PDF supplier invoices from October.
  2. Task: "Read every invoice in this folder and build invoices-october.xlsx with supplier, date, amount and VAT, plus a total row using formulas. Do not delete or move any PDFs."
  3. Cowork builds the workbook in the folder. Because his mode is Manual, it asks before writing the file, and he approves.
  4. He spot-checks five invoices against the sheet and finds one where VAT was read as zero; he asks Claude to re-read that file and fix the row.
  5. The next week he closes the laptop mid-task. The cloud session keeps working on the parts that do not need his files, and finishes once he reopens the app and the folder is reachable again.

Common problems on Windows

  • Cowork option missing. Check you are on a paid plan and the latest app version. On Team or Enterprise, an owner may need to enable it.
  • Claude cannot see your files. The app must be open and connected, and the folder must be one you connected. Synced cloud folders may need files downloaded locally first.
  • Built-in browser keeps asking you to sign in. On Windows, cookie import only works from Firefox; sign in once inside the built-in browser or use Claude in Chrome.
  • Usage runs out quickly. File work and long tasks use more of your plan than chat. Batch related jobs and check Settings > Usage.

Does Claude Cowork work on Windows 10 and Windows 11?

Anthropic lists Claude Desktop for Windows on all paid plans. Check the download page for the current minimum Windows version before installing.

Can I use Cowork on Windows without the desktop app?

Yes, on the web if your plan includes it, but Claude can only reach your local files, browser and screen through the desktop app.

Is Cowork free on Windows?

No. Cowork needs a paid plan (Pro, Max, Ultra, Team or Enterprise) on every platform.

Does Cowork keep working if my Windows PC goes to sleep?

Sessions run in the cloud and keep going, but steps that need your local files or browser wait until the app is open and connected.

Is Cowork on Linux?

Anthropic lists Claude Desktop for Linux as beta, so expect some features to lag behind Windows and macOS.
