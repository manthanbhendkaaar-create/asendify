How do you set up Claude Cowork for the first time, and what is /setup-claude?

By Manthan Bhendkar · 6 min read · Published 20 November 2026 · Last updated 20 November 2026

Disclosure: Asendify publishes this page and makes some of the options mentioned here; ours are named as ours. Every option is described from its own official page, and prices and features can change, so check before you buy.

To set up Claude Cowork, open the Claude desktop app (or claude.ai) on a paid plan, choose Cowork, and type /setup-claude. Claude walks you through picking your role, installing a plugin for it and connecting the tools that plugin uses, such as Slack, Google Workspace or Microsoft 365. Then give Cowork a place to work, a folder on your computer or a project, and start with a small, multi-step task.

Key takeaways

  • Cowork needs a paid plan; the desktop app runs on macOS, Windows and Linux (beta), and web and mobile are available on most paid plans.
  • /setup-claude is a guided set-up inside the conversation: role, plugin, connectors. You can run it again any time.
  • Use the desktop app when the work involves files on your computer; folders need the desktop app.
  • Projects keep their own files, instructions and memory across sessions.
  • Before real work, add global instructions (Settings > Cowork) and read Anthropic's safety guide.

The three set-up steps

Anthropic Academy's tutorial Get started in Claude Cowork in three steps sets them out:

  1. Open Claude. Use the desktop app or claude.ai and sign in. If the message box shows a Cowork option, select it. "Use the desktop app when the work involves files on your computer."
  2. Run /setup-claude. Type it and press Enter. Claude guides you through choosing your role, installing a plugin that matches it, and connecting the tools that plugin uses. The tutorial describes a plugin as packaging "the skills, connectors, and slash commands for a role". Type / afterwards to see the commands your plugin added.
  3. Give Cowork a place to work. Add a folder (desktop) scoped to one piece of work, or a broader directory several tasks share; Cowork finds relevant files and saves what it makes there. Or pick a project, which keeps its own files, instructions and memory across sessions.

Add your standing instructions

Anthropic's onboarding tutorial Set up Cowork to work the way you do recommends two layers of instructions:

  • Global instructions in Settings > Cowork (click Edit), for rules that apply everywhere, such as "save drafts as .docx" or "ask before deleting anything".
  • Project instructions in the project's instructions box: your role, default output format, where things live and the judgement calls you want handled the same way.

It also suggests checking what Claude has picked up by asking: "tell me what you know about how I work here."

Safety settings before real work

  • Approval mode: Auto is the default on Pro, Max and Team; switch to Manual for anything that sends, buys or deletes. Permanent deletion always needs your "Allow".
  • Folders: connect a dedicated working folder, not your whole drive.
  • Connectors: review which tools are "Always allow", "Needs approval" or "Blocked".
  • Usage: multi-step tasks use considerably more of your plan than chat; check Settings > Usage.

Good first tasks

The Academy tutorial suggests tasks that span several tools or steps, such as:

  • "Turn the research in this folder into a one-page brief."
  • "Write a status summary from last week's Slack and Linear activity."
  • "Update the forecast model with the figures from these PDFs."

Worked example

Example: Ben runs a three-person bookkeeping practice on a Pro plan and installs Cowork on his Mac.

  1. Open and set up: he opens the desktop app, selects Cowork and types /setup-claude. He chooses a finance-related role, installs the suggested plugin and connects Gmail and Google Drive.
  2. Place to work: he creates a folder called "Cowork - Client admin" and connects only that folder.
  3. Instructions: global: "UK English. Never send emails; leave drafts. Ask before deleting anything." Project: "Client documents arrive by email with the label Clients. Reconciliation sheets live in Drive > 2026."
  4. First task: "Read the three client PDFs in this folder and draft a one-page summary of what each client still owes." He watches in Manual mode, approves each step and checks the totals himself.
  5. Day five: happy with the results, he switches to Auto for reading tasks, keeps email sending blocked and plans a Monday scheduled summary for week two.

Common set-up mistakes

  • Connecting every tool on day one. Start with the one or two your first tasks need; add more as you go.
  • Pointing Cowork at your whole home folder. Anthropic's safety guide recommends a dedicated working folder.
  • Skipping instructions. Without them you repeat the same context in every prompt.
  • Starting with something irreversible. Drafts first, sending later.
  • Expecting chat-style usage. Multi-step tasks use far more of your plan, so check Settings > Usage after your first few runs.
  • Never re-running /setup-claude. If your work changes, run it again to swap plugins and connectors.

What does /setup-claude do?

It runs a guided set-up in the conversation: choose your role, install a matching plugin and connect the tools it uses. You can run it again any time.

Do I need the desktop app?

For files on your computer, yes. Cowork also runs on web and mobile on most paid plans.

Can I use Cowork on the free plan?

No. Anthropic's help centre says Cowork requires a paid plan.

Should I use a folder or a project?

A folder works on files on your computer; a project keeps its own files, instructions and memory across sessions. Many people use both.

What should my first task be?

Something multi-step but low risk, such as turning a folder of notes into a one-page brief.
