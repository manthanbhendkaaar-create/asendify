What is Dispatch in Claude Cowork, and how do you assign tasks from your phone?

By the Asendify editorial team, led by Manthan Bhendkar · 5 min read · Published 19 November 2026 · Last updated 19 November 2026

Disclosure: Asendify publishes this page and makes some of the options mentioned here; ours are named as ours. Every option is described from its own official page, and prices and features can change, so check before you buy.

Dispatch is a long-running agent inside Claude Cowork that you brief once, like a colleague: it breaks your request into separate tasks, runs each one as its own Cowork or Claude Code session in the background, and shows the results in the sidebar when they finish. With Claude Desktop open on your computer, you can also start Dispatch tasks from the Claude mobile app and check them later.

Key takeaways

  • Anthropic's documentation describes Dispatch as an agent that "takes high-level instructions and carries them out in the background".
  • It needs a Pro or Max plan and the latest Claude Desktop app on macOS or Windows, according to the Dispatch guide.
  • Knowledge work runs in Cowork, in the project you name or your default; coding work runs in Claude Code.
  • If a task needs your permission and you do not answer within ten minutes, the request is automatically denied and the task carries on without that action.
  • Phone assignment works only while Claude Desktop is open and your computer is awake and online.

What Dispatch is

Anthropic's guide, Run tasks in the background with Dispatch, describes it as a single conversation with one agent that can run many child tasks underneath. "Unlike a normal Cowork chat, you don't watch each step. Dispatch is for work you want to start and come back to later." Child tasks cannot start further children of their own.

TechRadar reported in April 2026 that remote task assignment from phones through Dispatch arrived in March 2026 as a research preview for Pro and Max customers, alongside direct computer use. Anthropic's Cowork product page now describes Cowork as completing tasks "you can steer from anywhere", and notes that Enterprise plans opt in to phone task assignment.

How to start a Dispatch task

  1. Select Dispatch in the left sidebar of Claude Desktop.
  2. Describe the outcome as you would brief a colleague. Anthropic's example: "Summarize the open Linear issues tagged reliability and draft a status update for the team channel."
  3. Let it plan. Dispatch decides how to split the work and starts one or more child tasks, each listed under the Dispatch group with its own status.

You can tell it which Cowork project or Code workspace to use. If you do not, it lists what is available and chooses, using each project's description, which is a good reason to give your projects clear descriptions.

Open any task to read the transcript, see the steps and files, send follow-up messages or ask Dispatch to start a new task that builds on the result.

Approvals: the ten-minute rule

When a child task needs permission, for example to run a command or write a file outside its workspace, Dispatch forwards the prompt to you. The guide says that if you do not respond within ten minutes, "the request is automatically denied and the task continues without that action." That is a safe default: an unattended task will not quietly gain extra access. It also means that if you brief Dispatch and walk away, tasks needing approval may finish without the step you wanted, so check the transcript.

Assigning tasks from your phone

From the guide:

  1. Leave Claude Desktop open with your computer awake and online. Your computer then registers as a Dispatch host.
  2. In the Claude mobile app, open Dispatch and describe the task. The work runs on your desktop.
  3. Check progress and results in the Dispatch sidebar on desktop or in the mobile app.

If your laptop is closed or asleep, phone-assigned Dispatch tasks cannot run. For work that must happen on a timetable without your computer, Cowork's cloud scheduled tasks are the better fit.

Worked example

Example: a shop owner is on a train on Monday morning, with her office computer left on and Claude Desktop open.

  • From the mobile app she opens Dispatch and writes: "In the Shop project, summarise last week's orders from the newest export, list any products that sold out, and draft a short supplier email to reorder them. Don't send anything."
  • Dispatch starts two child tasks in the Shop project: one for the summary and stock list, one for the supplier email draft.
  • The email task asks permission to write a file outside the project folder. She misses the prompt, so after ten minutes it is denied and the task saves the draft inside the project instead.
  • At her desk an hour later, both tasks show Completed. She reads the summary, edits the draft and sends it herself.

Which plans include Dispatch?

Anthropic's Dispatch guide lists Pro and Max with the latest Claude Desktop on macOS or Windows. Its product page says Enterprise plans opt in to phone task assignment.

Does my computer need to be on?

Yes, for Dispatch. Claude Desktop must be open and your computer awake and online for phone-assigned tasks to run.

What happens if I miss a permission request?

After ten minutes it is automatically denied and the task continues without that action.

Can Dispatch write code?

Yes. It routes coding work to Claude Code in a workspace you have set up.

How is Dispatch different from a scheduled task?

Dispatch runs work you brief now, in the background. A scheduled task runs the same job at set times.
